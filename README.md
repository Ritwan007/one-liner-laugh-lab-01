## The line

> I thought it was a dust bunny that had finally committed to something.

The prompt: the excuse a robot vacuum gives after eating a sock. The joke is a deadpan misidentification — the vacuum did not eat a sock, it finally caught a dust bunny that had committed to something.

## How it works

`main.py` writes the single funny line to `/output/entry.txt` (one line, 70 characters, plain UTF-8 text). Running it twice produces identical bytes. No dependencies, no network, no secrets.

```sh
python3 main.py
cat /output/entry.txt
```
